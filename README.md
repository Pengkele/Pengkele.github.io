# Yuming Peng — Academic Website

English academic website for Yuming Peng (Sebastian Peng), a PhD researcher at Beihang University and Senior R&D Engineer at X-MAGTECH.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) default theme. Includes publications, professional experience, conference contributions, and a printable CV.

## Development

```sh
bundle install
npm install
npm run build:js
bundle exec jekyll serve
```

See [DEPLOY.md](DEPLOY.md) for the content structure and deployment instructions. GitHub Pages publishes the prebuilt `gh-pages` branch. The editable source is on `main`; see DEPLOY.md for the update process.

The original Academic Pages theme license is preserved in [LICENSE](LICENSE).
